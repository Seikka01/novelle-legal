# Assistance Novelle

**Application : Novelle – Romans FF**

Pour toute demande d’assistance, vous pouvez nous contacter à l’adresse suivante :
[seikkastudio.contact@gmail.com](mailto:seikkastudio.contact@gmail.com).

Vous pouvez notamment nous écrire pour :

- signaler un bug ;
- résoudre un problème de connexion ;
- demander de l’aide concernant votre bibliothèque ;
- signaler une erreur dans une fiche de livre ;
- obtenir de l’aide sur l’utilisation de l’application.

Dans votre message, merci de décrire aussi précisément que possible le problème
rencontré. Si vous la connaissez, indiquez également la version de l’application
Novelle installée sur votre appareil.
